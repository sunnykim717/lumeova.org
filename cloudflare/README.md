# 회원가입 이메일 인증 UI

운영 도메인: https://lumeova.org
기존 Cloudflare Worker: lumeova-website

2026-11-08: 운영 이메일 인증은 main 브랜치의 Next.js 폼 외부에서 추가된 Worker 스크립트가 처리하고 있습니다. 기존 운영 모듈과 정적 자산을 보존하고 이메일 인증 UI만 갱신합니다. 현재 저장소 전체를 그대로 재배포하면 운영 전용 기능이 사라질 수 있으므로 주의해야 합니다.

## 변경

- 개인정보 동의·Turnstile 다음에 이메일 인증 영역을 배치합니다.
- 세션·발송·응답 본문 읽기를 포함해 20초 시간 제한을 적용합니다.
- 세션 실패는 다음 클릭에서 새로 준비하고, 서버 실패·잘못된 응답을 명확히 표시합니다.
- 발송 시간 초과는 자동 재발송하지 않으며 60초 대기 후 사용자가 다시 요청합니다.
- OTP 발급 정보와 확인 성공 응답을 검사합니다.
- 이메일 변경 시 인증을 해제하고 제출을 차단합니다.
- 화면 갱신으로 인증 영역이 제거되면 기존 이벤트가 연결된 영역을 복구합니다.

## 테스트

Node.js 22 이상, jsdom 31:

    npm run test:membership

실기기 카카오톡 검증은 자동 DOM 테스트나 화면 폭 검사로 대체할 수 없습니다.

## 운영 적용

공식 API에서 현재 운영 Worker의 모든 모듈과 현재 제공되는 UI를 다운로드하고 아래 명령으로 후보를 만듭니다. 원본 UI가 운영 번들과 정확히 일치하지 않으면 중단합니다.

    node scripts/prepare-membership-hotfix.cjs <운영모듈폴더> <현재UI파일> <후보폴더>

후보 폴더의 served-ui.js는 테스트용 파일이며 Worker 업로드에 포함하지 않습니다. membership-worker.js만 변경하고 나머지 모듈은 원본과 해시가 같아야 합니다. 새 UI URL은 /_lumeova-membership/20261108-v16.js 입니다. Cloudflare API 업로드는 keep_assets와 strict 모드의 binding inherit를 사용해 기존 자산·비밀키·서비스 연결을 보존해야 합니다. 데이터베이스 마이그레이션은 없습니다.
