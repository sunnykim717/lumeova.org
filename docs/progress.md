# 미래를여는빛 홈페이지 작업 기록

마지막 갱신: 2026-10-23

이 문서는 작업 내역, 실행한 데이터베이스 마이그레이션, 검색엔진 등록 상태, 남은 과제를 기록합니다.
비밀번호와 비밀키는 기록하지 않습니다.

## 1. 저장소와 배포

- GitHub 저장소: `sunnykim717/lumeova.org`
- 기본 브랜치: `main` (Cloudflare Workers 프로젝트 `lumeova-website`가 연결되어 배포)
- 작업 브랜치: `claude/epic-hopper-vh1xli`
- 공식 도메인: `https://lumeova.org`
- 최근 병합: PR #13(CMS 1단계), #14(현장 이야기 사이트맵), #15(네이버 인증 태그)

## 2. 완료한 기능

- 메인 화면 슬라이드, 단체 소개, 참여 안내 문구를 관리자 화면(홈 화면)에서 수정
- 사업 페이지 소개 글 (교육지원, 리더십 지원)을 코드에 반영
- 현장 이야기: 국가별 분류, 목록·상세, 관리자 등록·수정·삭제, BAND 글 붙여넣기 가져오기, 공개 검토 단계
- 회원가입 페이지의 정회원 모집 현황(승인된 정회원 수 기준)
- 메뉴 구조: 후원자 모집 › 회원가입 › 일반회원·정회원, 사업 › 교육지원·리더십지원, 활동 › 현장 이야기
- 관리자 휴지통(복구·영구 삭제), 변경 이력 화면
- 계좌번호 복사 버튼
- 반응형 점검: 320~1920px 모든 공개 페이지에서 가로 넘침 없음 (수정: 단체 소개 CI 카드)
- 사이트맵에 브랜드 페이지와 현장 이야기 글 포함

## 3. 데이터베이스 마이그레이션

| 파일 | 내용 | 실행 상태 |
|---|---|---|
| 0001_init.sql | 기본 테이블과 권한 | 실행 완료 |
| 0002_site_content.sql | 홈 화면 콘텐츠 | 실행 완료 |
| 0003_supporter_drive.sql | 후원자 집계 함수 | 실행 완료 |
| 0004_regular_member_count.sql | 정회원 승인 기준 집계 | 실행 완료 |
| 0005_project_category.sql | 사업 영역 열 | 실행 완료 |
| 0006_field_stories.sql | 현장 이야기 테이블 | 실행 완료 |
| 0007_cms_foundation.sql | 휴지통 열, 역할별 쓰기 권한 | 실행 완료 |

관리자 계정은 `super_admin` 역할입니다. 권한 조회 문제(GRANT)는 `admin_users`에 대한 읽기 권한을 추가해 해결했습니다.

## 4. 검색엔진 등록 상태

| 검색엔진 | 등록 | 소유권 확인 | 사이트맵 | 상태 |
|---|---|---|---|---|
| Google Search Console | 완료 | 완료 (DNS TXT) | 제출, 성공 (페이지 12개 발견) | 수집 진행 중 |
| 네이버 서치어드바이저 | 완료 | 완료 (HTML 태그) | 제출 완료 | 수집 대기 |
| 다음 검색등록 | 완료 | 등록 절차에 따름 | 확인 필요 | 심사 결과 확인 필요 |
| Bing Webmaster Tools | 미완료 | - | - | 집 컴퓨터에서 진행 예정 |

주의: Google DNS TXT 레코드와 네이버 인증 메타 태그는 삭제하지 않습니다.

## 5. 남은 과제

- Bing 등록 (집 컴퓨터에서 진행, 소유권 확인 후 사이트맵 제출)
- 다음 검색등록 심사 결과 확인
- 네이버, Google 색인 상태 주기적 확인
- 관리자에서 편집할 수 없는 공개 문구 (단체 소개 미션·비전·핵심가치·철학·연혁, 활동 소개, 사업 소개 일부, 회원가입·후원·문의·법률 문구)
- 페이지별 검색 제목과 설명을 관리자에서 편집하는 기능
- 사진·파일 관리 (업로드, 사용 중 파일 확인)
- 리치 텍스트 편집기, 미리보기, 게시 승인, 버전 복원
- 관리자 사용 설명서 작성
- 관리자 화면 실제 테스트 (휴지통 복구, 변경 이력 확인)
- 관리자 후원자 명단은 정기후원 기준 표시이며, 공개 집계는 정회원 기준이므로 기준을 맞출지 결정 필요
- 법률 검토가 필요한 개인정보 처리방침과 이용약관 확정
- 단체 소재지 상세 주소 (계산동) 확정 여부 결정
